# RED<span class="y">code</span> docs

REDcode is a Cyberpunk 2077 modding IDE built on VS Code. It is a preview on the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Edgemodders.redcode-cyberpunk) and [Open VSX](https://open-vsx.org/extension/edgemodders/redcode-cyberpunk) as **REDcode for Cyberpunk 2077**: search for that name in VS Code's Extensions view (Ctrl+Shift+X). On first start it finds the game and offers to download REDbridge, the local program that runs WolvenKit's libraries.

## Roadmap status

| Phase | Status |
|---|---|
| C0 Decide | Done. See the REDbridge docs for the WolvenKit build findings |
| C1 Bridge MVP | Done. The extension (then `redcode-core`, now `redcode`) opens a game file as JSON through REDbridge |
| C2 Browse | Done. Project view over `.cpmodproj`, Game Assets tree, add to project, extract, open as JSON. Verified by hand on 2026-10-11: a project made in REDcode opens and packs in WolvenKit, and Extract To matches WolvenKit's output |
| C3 Edit | Done. Verified by hand on 2026-10-11: Save JSON to Project (edits under `components` stick, `compiledData` is regenerated by WolvenKit, numbers are 32-bit floats), the texture viewer, TweakXL language support. The CR2W editor is designed ([design page](design/cr2w-editor.html)); E1 (bridge document sessions, REDbridge 0.5.0) and E2 (the editor: tree, property grid, undo and redo, backup and replay) are done and verified by hand on 2026-10-12. E3 (search across the file, the localization table view, `.json` and `.csv` CR2W files detected by their magic) on 2026-10-12, E4 (the atlas view) and E5 (the texture view, read-only game files, the Properties view) on 2026-10-13 |
| C4 Ship | Done ([design page](design/ship.html)). Pack, Install and Uninstall (through EDGEdeck when it is installed), Run Game, Export to Raw and Import from Raw, verified by hand on 2026-10-13 and 2026-10-14. Released in 0.6.0; on the stores since 0.8.2 |
| C5 View | V1 to V4 done ([design page](design/view.html)): the mesh viewer (0.7.0), the audio player and sound list (0.8.0), the TweakDB view (0.9.0), the LocKeys view (0.10.0). The MCP server is on npm. The script runner was dropped. To come: V5, the REDnode loop |
| C6 Parity | Not started. Quest and scene graphs moved to EDGEquest, layered material preview to EDGEmat |
| C7 Brand | Not started |
