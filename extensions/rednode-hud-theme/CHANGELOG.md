# Changelog

What changed in each REDnode HUD theme release. The release notes on GitHub come from these sections; changes are grouped as **New**, **Changed**, **Fixed** and **Other**, and older sections keep the form they had.

## Unreleased

## 0.3.1

- Publisher is now `edgemodders`, following the move to the Edgemodders organization. The extension id changes from `cyberbuildsai.rednode-hud-theme` to `edgemodders.rednode-hud-theme`, so VS Code sees a new extension: uninstall the old one after installing this version.

## 0.3.0

- Yellow folder icons in the REDcode views (`redcode.folder`) and for folder symbols in outlines and breadcrumbs.

## 0.2.0

- Activity bar: icons are yellow at rest and white on hover. The selected icon is white, marked by the yellow border.

## 0.1.0

- First release: REDnode HUD dark color theme covering the workbench, editor, terminal and syntax highlighting, including semantic tokens.
